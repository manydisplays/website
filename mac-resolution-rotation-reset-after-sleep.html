Mac resets monitor resolution, refresh rate or rotation after sleep

31 October 2026 · Martín Acuña Lledó · Applies to macOS 13 Ventura through macOS 27

You set your external monitor to the scaled resolution you like, or to 120 Hz, or turned one screen to portrait. Then the Mac sleeps, or you lock it, or restart, and when you come back the text is huge or tiny, the monitor is back at 60 Hz, or the portrait screen is landscape again. Often the arrangement has changed and windows have moved too. You open System Settings, fix it, and it happens again the next day. This page explains why macOS forgets these settings, how to see what it is using, and what you can do.

Why macOS forgets display settings

macOS keeps the resolution, refresh rate, rotation and position of each monitor it knows, and recognises a monitor by the vendor, model and serial number it reports. Three situations break that:

  • The monitor disconnects during sleep. DisplayPort, USB-C and Thunderbolt monitors drop their link when they sleep. When they come back, macOS has to recognise them again and apply the stored settings. If a monitor wakes slowly or reconnects in a half-ready state, macOS can fall back to the monitor's default mode, which is often a different scaled resolution or 60 Hz.
  • Two identical monitors get mixed up. If two monitors of the same model report the same serial, macOS cannot tell which one it is talking to. The settings of one end up on the other: the portrait rotation lands on the monitor that should be landscape, or each one gets the other's scaled resolution. See two identical monitors swap places after sleep.
  • A dock changes how the monitor is seen. Through a dock or a different cable, the same monitor can be offered different modes. Some docks also limit bandwidth, so a high refresh rate may not be offered every time the monitor reconnects.

The built-in screen of a MacBook can be affected too: after you undock, it sometimes comes back at a resolution you did not choose.

Check what macOS is using

In Terminal, this shows the native resolution of each display and the scaled resolution and refresh rate macOS is using right now:

system_profiler SPDisplaysDataType | grep -E "Resolution|UI Looks like"

The "UI Looks like" line is the one that matches the size you picked in System Settings → Displays, followed by the refresh rate. Run it once when everything is right and once after a wake where it went wrong: if the line changed, macOS applied a different mode on reconnect.

Fixes without an app

  • Keep the monitors connected while you are away. Turn off "DisplayPort deep sleep", "Deep sleep" or "Auto standby" in each monitor's menu, and in System Settings → Lock Screen set "Turn display off when inactive" to Never with a password-protected screen saver. No disconnect, nothing to forget. This covers the lock case; see Mac loses window positions when you lock it.
  • Re-apply the settings with displayplacer. This free command-line tool saves and re-applies resolution, rotation, arrangement and main display. Run displayplacer list once to get the command for your setup and run that command after each wake. It does not move windows, and with identical monitors the IDs it relies on can change between sleeps.
  • Keep each monitor on the same port and cable. Moving a monitor to another port or through a dock can change the modes it offers. If a refresh rate keeps dropping, try the monitor directly on the Mac.
  • Separate identical monitors. If a portrait monitor keeps turning landscape and you have two of the same model, give each its own port on the Mac. On Apple silicon the port is what can tell them apart.

What those fixes do not cover

  • Full sleep, a restart or unplugging the dock still disconnect the monitors.
  • A script that restores the mode does not restore windows. If the resolution changed while windows were on screen, they may have been resized or moved, and they stay that way.
  • A mode that the monitor or dock does not offer at that moment cannot be applied by anything.

How Many Displays handles it

Many Displays remembers the mode of every display along with its windows, one layout per combination of displays. When the Mac wakes, unlocks or the monitors reconnect and the displays have been stable for a few seconds, it checks what macOS changed. If the arrangement, the main display, the resolution, the refresh rate, the rotation or HDR are not what they were, or macOS turned on mirroring by itself, it puts each one back, one step at a time, before it moves any window. Then every window goes back to its display, position and size. If a display's resolution did change, window positions are scaled proportionally.

When you undock and the built-in screen comes back at a wrong resolution, the last known good mode is restored. With the MacBook alone the app does not touch your windows. Putting display settings back can be turned off in the menu if you prefer to manage them yourself.

Since macOS 14.5 no app can move another app's window to a different desktop (Space) without disabling System Integrity Protection, so it restores display, position and size, not the desktop.

Questions

Why does my external monitor's resolution change after the Mac sleeps?

macOS stores the resolution, refresh rate and rotation for each display it recognises. A DisplayPort or Thunderbolt monitor disconnects during sleep, and when it reconnects macOS has to recognise it again. If it is reported differently, for example through a dock, or if two identical monitors are mixed up, macOS applies its default mode or another monitor's settings.

Why does my portrait monitor go back to landscape?

Rotation is stored per display, like resolution. If macOS mixes up which monitor is which after a reconnect, the rotation ends up on the wrong screen or is lost. It happens most with two monitors of the same model, one of them in portrait.

How do I check the resolution macOS is using?

Run system_profiler SPDisplaysDataType | grep -E "Resolution|UI Looks like" in Terminal. The UI Looks like line shows the scaled resolution and the refresh rate macOS is using right now.

Will displayplacer keep my resolution and rotation?

It can re-apply them after each wake, together with the arrangement and the main display. You have to run it, or have something run it, every time, and it does not move windows.
