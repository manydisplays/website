Monitor colour profile changes after sleep on a Mac

24 November 2026 · Martín Acuña Lledó · Applies to macOS 13 Ventura through macOS 27

You calibrated your monitor, or picked the profile that looks right, and after the Mac wakes the picture is off: washed out, too contrasty, or obviously back to a generic profile. You pick the right one again in System Settings and it holds until the next sleep. This page shows where macOS sets the profile, how to check which one is really in use, what people found as causes, and the fixes. My app does not restore colour profiles, and the page says so at the end.

Check which profile is in use

  1. System Settings → Displays. Select the monitor. Apple's Displays settings page describes the Color profile option as changing the color profile your display uses. Note what it says now, and what it said before the sleep.
  2. ColorSync Utility. It is in Applications → Utilities. Click Devices in the toolbar, open the Displays group and select your monitor. Apple's guide says it shows the device's default (factory) profile and its current profile.
  3. Compare after a wake. If the current profile changed while you were away, macOS applied a different one. If the profile name is the same but the picture changed, look at HDR instead: see external monitor HDR turns off after sleep.

What people found

There is no single cause, and the reports point at different ones:

  • A cleaning app. In a MacRumors thread from July 2025, a Mac mini M4 user on macOS Sequoia 15.5 found that a custom profile loaded fine at boot but reverted to sRGB after sleep or the screen saver. In August they wrote that the cause was CCleaner, which they say deleted the current ColorSync settings. If you run a cleaner or "maintenance" app, check it first.
  • Identical monitors getting each other's profile. In an r/MacOS thread about identical monitors swapping after sleep, a user with two identical monitors on an OWC dock wrote that, although the monitors are identical, they have different colour profiles, so when they swap each one ends up with the other's profile. That fits with macOS keeping a profile per monitor it recognises. See two identical monitors swap places after sleep.
  • The display turning off and on. In a 2019 MacRumors thread on a 16-inch MacBook Pro, users report the profiles messed up after every wake. One says it happens when the screen turns off after the energy setting's timeout. Another says turning automatic brightness off and on fixes it for them.
  • Wide-gamut colour lost after sleep. In a 2022 MacRumors thread, a Mac mini user with a wide-gamut LG monitor says colour tests fail after a wake, and switching HDR off and on restores them.

Fixes without an app

  • Pick the profile again. In System Settings → Displays, or in ColorSync Utility: select the display under Devices, click the Current Profile pop-up menu, choose Other, then select the profile, as Apple's ColorSync Utility guide describes.
  • Remove cleaning apps that touch preferences or ColorSync, then set the profile again and test a few sleeps.
  • Separate identical monitors. If two monitors of the same model swap profiles, give each its own port on the Mac so macOS can tell them apart. On Apple silicon the port is the clue that holds.
  • Keep the monitor from turning off while you are away. If the reset happens when the display sleeps, set "Turn display off when inactive" to Never in System Settings → Lock Screen and use a password-protected screen saver. See Mac loses window positions when you lock it.
  • Try HDR off and on if colours look wrong but the profile name has not changed. That is what the 2022 MacRumors poster found.
  • Calibrate again. Apple's Displays settings page says you can create your own profile by calibrating your display. A fresh profile rules out a damaged one.

In the 2019 thread, one developer posted a small open source app that switches the profile back automatically on wake. I have not tested it.

What those fixes do not cover

  • Picking the profile again is manual and lasts until the next time it breaks.
  • Keeping the display on does nothing for real sleep or a dock.
  • With identical monitors from the same batch behind one dock, macOS may have nothing to tell them apart, so their profiles can keep swapping.

Questions

How do I check which colour profile my monitor is using?

Open ColorSync Utility from Applications → Utilities and click Devices in the toolbar. Apple's guide says it shows each device's default (factory) profile and its current profile. System Settings → Displays also has a Color profile setting for each display.

How do I set it back?

Pick the profile again in System Settings → Displays for that monitor, or in ColorSync Utility: select the display under Devices, open the Current Profile pop-up menu, choose Other and select the profile.

Why does the profile change after sleep?

Reports point to different causes. In one 2025 MacRumors thread the cause turned out to be a cleaning app that deleted ColorSync settings. With two identical monitors, macOS can mix them up after sleep and give each one the other's profile. In other reports the profile resets when the display turns off and on.

Does Many Displays restore colour profiles?

No. It restores arrangement, resolution, refresh rate, rotation, HDR and windows, not colour profiles.
