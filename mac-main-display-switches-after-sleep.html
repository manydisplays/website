Mac main display switches to the other monitor after sleep

28 November 2026 · Martín Acuña Lledó · Applies to macOS 13 Ventura through macOS 27

Your monitors are in the right order after a wake, but the menu bar is on the wrong one. New windows open there, and with "Displays have separate Spaces" off the Dock goes there too. You drag the menu bar back in System Settings, and the next morning it has moved again. This page explains why macOS changes the main display, how to check it, how to pin it without my app, and what my app does.

Why the main display changes

The main display is the one with the menu bar. macOS remembers which monitor that is, like it remembers the arrangement and resolution. When a DisplayPort, USB-C or Thunderbolt monitor sleeps, it usually drops its link, and when it comes back macOS has to recognise it again.

With two monitors of the same model that report the same serial number, macOS cannot always tell which is which. Usually that swaps their positions. Sometimes the positions survive and only the main-display role moves. A BetterDisplay user described exactly that in March 2025: with layout protection on, two identical monitors stayed on the correct side, "but now my main display swaps between the two". Background on identical monitors is in two identical monitors swap places after sleep.

On a Mac mini or Mac Studio, the main display also decides where every window piles up after a wake. That case is covered in every window on the main display after wake.

Check and set the main display

In Terminal, this lists your displays and marks the main one:

system_profiler SPDisplaysDataType | grep -E "Main Display|Online"

Run it before the Mac sleeps and after it wakes. If "Main Display: Yes" moved to another monitor, macOS changed it during the wake.

To set it back, open System Settings → Displays. Apple's Displays settings page says the "Use as" option chooses whether a display mirrors, extends or acts as your main display. You can also drag the white menu bar onto the monitor you want in the arrangement.

Fixes without my app

  • Give identical monitors their own ports. On Apple silicon, the physical port is what can tell two identical monitors apart. Behind one dock they usually share a port.
  • Keep the monitors connected while you are away. In System Settings → Lock Screen, set "Turn display off when inactive" to Never and use a password-protected screen saver, and turn off deep sleep in each monitor's menu. A monitor that never drops its link is never re-recognised. See Mac loses window positions when you lock it.
  • Put the main monitor on HDMI if your Mac has an HDMI port. HDMI monitors usually stay connected while asleep, so the main one does not disappear.
  • Set it with displayplacer. In the free command-line tool, the screen placed at origin (0,0) becomes the main display, according to its README. Save the command once and run it after a wake. Its own README warns that screen IDs can change with identical monitors. See fix swapped monitors with displayplacer.
  • BetterDisplay's main display protection. In that BetterDisplay issue, its developer pointed the user to a main display protection setting under Configuration Protection. I have not tested it.

What those fixes do not cover

  • Keeping the monitors on does nothing for a real sleep, a restart or unplugging a dock.
  • Setting the main display back does not move the windows that already followed it to the wrong screen.
  • Two identical monitors from the same batch behind one dock can match on everything macOS sees, so any tool that relies on IDs can still pick the wrong one.

How Many Displays handles it

Many Displays keeps one layout per combination of displays, including which one is main. When the Mac wakes, unlocks or the monitors reconnect and the displays have been stable for a few seconds, it checks what macOS changed. If the main display or the arrangement are not what they were, it puts them back first, then the resolution, rotation and HDR, and then every window to its display, position and size.

It tells identical monitors apart by system UUID, then by the physical port on Apple silicon, then by the EDID manufacture date, and only then by position, so it does not depend on IDs that change between sleeps.

Where it does not help:

  • Identical monitors from the same batch behind one dock. Serial, port and date can all match, and only position is left, which is what macOS may have swapped.
  • If you turn display fixes off. Putting display settings back can be turned off in the menu.
  • The Dock's position. It does not move the Dock. With "Displays have separate Spaces" off the Dock stays on the main display, so fixing the main display brings it back too. See the Dock jumps to the other monitor.

Questions

Why does my main display change after sleep?

Monitors that drop their link during sleep have to be recognised again when they come back. If two monitors are identical and report the same serial, macOS can mix them up and give the main-display role to the wrong one, even when their left and right positions are right.

How do I see which display is main?

Run system_profiler SPDisplaysDataType | grep -E "Main Display|Online" in Terminal. The display marked Main Display: Yes is the one with the menu bar.

How do I set the main display back?

In System Settings → Displays, select the monitor and use the Use as menu, or drag the white menu bar onto it in the arrangement. The free tool displayplacer sets it from a command: the screen placed at origin (0,0) becomes the main display.

Does Many Displays fix the main display?

Yes. If macOS changed the main display after a wake, unlock or reconnect, it puts it back along with the arrangement, before moving windows. With two identical monitors from the same batch behind one dock it may have nothing to tell them apart except position.
