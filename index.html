The problem

Your Mac sleeps. macOS piles every window onto one monitor, and swaps identical monitors because they share a serial number. You drag everything back. Every single time.

What it does

Lives in the menu bar. Install it once and forget it: it saves while you work and restores on its own when the Mac wakes, unlocks, or you plug the monitors back in. You never need to open it.

Works with identical monitors

Two, three or more of the same model that share a serial number are told apart by their system UUID, then by the physical port they are plugged into, and only then by position. One layout is kept per combination of displays.

Fast, and it never hangs

Other tools ask every app for every window through Accessibility, which is slow and stalls when one app stops responding. Many Displays reads the window server's list instead: around 20 ms for hundreds of windows, without talking to any app.

Restores the displays too

If macOS swapped left and right, changed the main display, resolution, refresh rate, rotation or HDR, or turned on mirroring after a reconnect, each one is put back before the windows. Can be turned off in the menu.

Every desktop, not just the visible one

Windows on your other desktops (Spaces) are remembered and restored too, without switching to them. With ten desktops across two monitors, everything comes back at once. Mission Control swipes and animations are never mistaken for a layout change.

A calm restore

While windows move, the screens get a soft blur with a countdown, so you are not watching windows jump around. It only appears when something actually needs to move and never stays longer than 10 seconds. Optional.

Private by design

No network access, no analytics, no account in the app. Your layouts stay in a JSON file in your Library folder. The source is published on GitHub, so you can read exactly what it does.

How it works

Tracks windows in near real time

When you move, resize, open or close a window, the layout is saved within about 1.5 seconds, plus a light check every 20 seconds. With the MacBook alone and no external displays it goes idle: no observers, no timers.

Freezes while macOS reshuffles

On lock, sleep, display sleep or a reconnect, saving stops. Whatever macOS does to your windows in the meantime is ignored, and the last good layout is kept.

Restores on its own when the displays are stable

No shortcut, no click. Once the displays have been steady for a few seconds, the arrangement is fixed first, then every window goes back in several quick passes, because macOS keeps nudging windows for a while. For three minutes afterwards, changes nobody asked for are undone instead of saved.

Questions

I have two (or three) identical monitors. Will this really work?

Yes, that is the case the app was built for, with any number of them. macOS identifies displays by vendor, model and serial number, and many monitors ship with the same serial (0 or 0x01010101), so two identical screens look the same to macOS and it shuffles them after every sleep. Many Displays tells them apart by their system UUID, then by the physical port they are plugged into (on Apple Silicon), and only then by position. If macOS swapped the arrangement, it is put back before the windows.

Does it restore windows to their Space (virtual desktop)?

It remembers the Space, but since macOS 14.5 Apple blocks moving other apps' windows between Spaces unless System Integrity Protection is disabled, so the app does not do it. In practice, with "Displays have separate Spaces" turned off, sleeping does not change a window's Space, only its display, which is what gets restored. If a window ends up on a different Space, the menu says so. Some apps hide their off-Space windows from Accessibility; those are restored the moment you switch to their Space.

Do I have to do anything after waking the Mac?

No. Sleep, lock, close the lid, unplug the dock, walk away: when the displays are back, Many Displays restores everything by itself, usually before you have sat down. There is a shortcut (⌃⌥⌘R) to restore on demand, but you should never need it. If you prefer to trigger restores yourself, turn off "Restore Windows Automatically" in the menu.

Does it work with the MacBook alone?

With no external displays the app goes idle and never touches your windows. Layouts are kept per combination of displays, so your desk setup and your lid-open setup are remembered separately. If undocking leaves the built-in screen at a wrong resolution, the last known good mode is restored.

Will it reopen windows I closed, or move new ones?

No. Windows you closed while away are never reopened, and new windows are left alone and tracked from then on.
