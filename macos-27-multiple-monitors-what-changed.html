macOS 27 and multiple monitors: what Apple fixed, and what it did not

14 November 2026 · Martín Acuña Lledó · Covers macOS 27.0 through 27.2.1

Every new macOS brings the same question in forums: did Apple finally fix monitors and windows after sleep? This page answers it for macOS 27 Golden Gate using only Apple's own documents: the developer release notes and Apple's support page for the 27.x updates, read on 14 November 2026. No rumours, no "seems better on my Mac". Then it covers what still applies if you have several monitors.

What the notes say is fixed

The macOS 27 release notes on Apple's developer site have three resolved issues that touch multi-monitor use:

  • The second identical display not lighting up. Under Thunderbolt: "When connecting to two identical displays (same model and serial number), the first display will work as expected whereas the second display might not light up." (176292156). If one of your two identical monitors sometimes stayed black, this is the fix for it.
  • A window lost after leaving full screen. Under Window Management: "When you exit a window from fullscreen mode using Mission Control, the window might be lost." (177660206)
  • The Dock staying on screen. Under Dock: "While using an app in full screen, the Dock might persist when entering and exiting Mission Control." (174992242)

Apple's support page "What's new in the updates for macOS 27 Golden Gate" lists 27.0.1 and 27.2.1 as bug fixes, and 27.2 with Siri, Messages, Photos, Podcasts and FaceTime changes. None of its entries mention displays.

What the notes do not mention

The problems people report most with several monitors are not in any of those notes:

  • Windows moving to another screen after sleep or lock. When a DisplayPort, USB-C or Thunderbolt monitor sleeps, it usually drops its link, and macOS moves its windows elsewhere and does not move them back. See Mac loses window positions when you lock it.
  • Identical monitors swapping places. The fix above is about the second monitor staying dark, not about which one is left and which is right. See two identical monitors swap places after sleep.
  • Resolution, refresh rate, rotation or HDR resetting after a wake. See resolution and rotation resets and HDR turns off after sleep.
  • Desktops (Spaces) ending up on the wrong monitor. See desktops move to the wrong monitor after lock.

The same was true of macOS 26. Its developer notes list one related known problem, that WindowServer crashes at login if "Displays have separate Spaces" is turned off (153570422), and nothing about windows moving after sleep. A missing entry does not prove nothing changed, since not every change is listed. But it means there is no documented reason to expect a difference.

Check your version

Choose Apple menu → About This Mac, or run this in Terminal:

sw_vers

It prints the product version and the build. The identical-display fix is in 27.0 and later.

What still helps without an app

Nothing in macOS 27 changes the advice. The short version:

  • Keep the monitors connected while locked. In System Settings → Lock Screen, set "Turn display off when inactive" to Never and use a password-protected screen saver, and turn off deep sleep or auto standby in each monitor's menu. This covers locks and idle time, not real sleep or a dock.
  • Turn off "Displays have separate Spaces" in System Settings → Desktop & Dock → Mission Control, so a window's desktop survives a disconnect. Given the macOS 26 note above, check that your Mac logs in normally afterwards.
  • Give identical monitors different ports. On Apple silicon, the physical port is what can tell two identical monitors apart. Behind one dock they usually share a port.
  • Re-apply the arrangement with displayplacer, a free command-line tool. It sets arrangement, resolution and rotation, not windows.

The full list is in every fix for windows moving after sleep.

Questions

Does macOS 27 fix windows moving to another monitor after sleep?

Not according to Apple's notes. The macOS 27 release notes and the update notes for 27.0.1, 27.2 and 27.2.1 do not mention windows moving between displays after sleep, lock or reconnecting, or the display arrangement being swapped.

What did macOS 27 fix for identical monitors?

One thing: when you connect two identical displays with the same model and serial number, the second one might not light up. The release notes list that as fixed (176292156). They say nothing about identical monitors swapping places.

Should I update to macOS 27 for my monitors?

If your second identical monitor sometimes stays black, the notes say that is fixed. If your problem is windows piling onto one screen or monitors swapping after sleep, the notes give no reason to expect a change, so the same settings and tools apply as before.

How do I check which macOS version I have?

Choose Apple menu → About This Mac, or run sw_vers in Terminal. It prints the product version and build.
