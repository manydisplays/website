Mac mini or Mac Studio puts every window on the main display after wake

28 October 2026 · Martín Acuña Lledó · Applies to macOS 13 Ventura through macOS 27

You leave your Mac mini or Mac Studio for the night, or just long enough for the monitors to go dark, and when you come back every window is stacked on the main display. The other monitors are empty. It happens after sleep, after the monitors turn themselves off, and often after a restart, and moving everything back is the first job of the day. A laptop at least has its own screen to fall back on; a desktop Mac only has the monitors, so everything lands on one of them.

Why desktop Macs do this

  • Sleeping monitors look unplugged. DisplayPort, USB-C and Thunderbolt monitors usually drop their link when they go to sleep. For the Mac, that is the same as pulling the cable out, so it moves the windows that were on that monitor to a display that is still there.
  • There is no built-in screen to fall back on. On a MacBook the windows land on the laptop screen. A Mac mini or Mac Studio has nothing else, so they land on whichever monitor is still connected or comes back first. That one often becomes the main display, the one with the menu bar, and collects everything.
  • macOS never moves them back. When the other monitors return a few seconds later, macOS treats them as freshly connected, empty screens. The windows stay where they were rescued.
  • Monitors wake in no fixed order. If a different monitor wins the race tomorrow, the pile ends up on a different screen, and with identical monitors the whole arrangement can swap. That case has its own page: two identical monitors swap places after sleep.

A common trigger is changing monitors. A typical story: a desk that behaved fine until one screen was replaced, and from then on every wake put all windows on the main display. A new monitor that drops its link on sleep, where the old one kept it, is enough to start it.

See which display macOS treats as main

In Terminal, this lists your displays and marks the main one:

system_profiler SPDisplaysDataType | grep -E "Main Display|Online"

Run it once before the Mac sleeps and once after you wake it. If the "Main Display: Yes" line moved to another monitor, macOS changed the main display during the wake, and the menu bar and your windows followed it. You can set the main display back in System Settings → Displays → Arrange by dragging the white menu bar onto the monitor you want.

Settings that reduce it

  • Keep the displays on and use a screen saver. In System Settings → Lock Screen, set "Turn display off when inactive" to Never and choose a screen saver that requires a password. The monitors never sleep, so they never disconnect. This is the most reliable fix for the daily case, at the cost of monitors that stay on.
  • Stop the Mac sleeping when the display is off. On a desktop Mac, System Settings → Energy has "Prevent automatic sleeping when the display is off". It removes the Mac's own sleep from the picture, so only the monitors can cause trouble.
  • Turn off deep sleep in each monitor's menu. Look for "DisplayPort deep sleep", "Deep sleep" or "Auto standby" in the monitor's settings. With it off, many Dell, LG and BenQ monitors keep the link alive while asleep.
  • Use HDMI for one of the monitors. The Mac mini and Mac Studio have an HDMI port, and HDMI monitors usually stay connected while asleep. Putting your main monitor on HDMI gives macOS a display that does not disappear. The trade-offs: HDMI limits on resolution and refresh rate depending on the model, and the other monitors still drop out.
  • Wake the monitors before you unlock. Press a key, wait until every monitor shows a picture, then log in. macOS lays windows out on whatever exists at each moment, so giving the monitors a head start reduces the shuffle.

The full list, including dummy plugs and scripts, is in every fix for windows moving after sleep. If it mostly happens when you lock the screen and walk away, see Mac loses window positions when you lock it.

What those settings do not fix

  • A full sleep of the Mac, a restart, or a power cut still disconnects every monitor.
  • Monitors that sleep on their own schedule, whatever the Mac says.
  • Identical monitors trading places when they reconnect.
  • Windows that already moved: none of these settings puts them back, they only make the move less likely.

How Many Displays handles it

Many Displays lets the monitors sleep and puts the windows back afterwards. It saves where every window is as you work, and the moment the Mac sleeps, locks or a display disconnects, saving freezes, so the pile on the main display is never recorded. When you come back, it waits until the displays have been stable for a few seconds, puts the arrangement, the main display, the resolution, the refresh rate and the rotation back first, and then returns every window to its physical display, position and size. It also does this when you log in, and it keeps one layout per combination of displays, so a different set of monitors is remembered separately.

You do not save layouts or press anything. If you ever want to restore by hand, Control-Option-Command-R does it. One limit that applies to every app: since macOS 14.5 no app can move another app's window to a different desktop (Space) without disabling System Integrity Protection, so it restores display, position and size, not the desktop.

Questions

Why does my Mac mini put every window on one monitor after sleep?

A Mac mini or Mac Studio has no built-in screen. When its monitors sleep and drop their DisplayPort or Thunderbolt link, macOS moves their windows to whatever display is left, and the first display to come back usually becomes the main one. The windows end up there, and macOS does not move them back when the other monitors return.

How do I choose which monitor is the main display?

In System Settings, Displays, Arrange, drag the white menu bar to the monitor you want as main. That decides where the menu bar and new windows go, but it does not stop macOS from moving windows when a monitor disconnects.

Does keeping the Mac mini awake fix it?

Partly. Turning off automatic sleep when the display is off avoids the Mac's own sleep, but the monitors still sleep and disconnect. To stop the daily case you also need the displays to stay on, with a screen saver instead of display sleep, or a monitor that keeps its link alive while asleep.
