MacBook built-in display looks wrong after undocking

11 November 2026 · Martín Acuña Lledó · Applies to macOS 13 Ventura through macOS 27

You work with the MacBook closed on a dock with external monitors. You unplug it, open the lid, and the built-in screen is wrong: everything is too big or too small, System Settings shows a list of raw resolutions instead of the usual size options, or the menu bar is squashed with items hidden behind the notch. You pick a resolution, it still looks off, and it happens again the next time you undock. This page covers what people report, how to see the mode macOS is using, what you can do without an app, and what none of it fixes.

What people report

The most followed thread on this in the Apple Community, "Menubar resizes after disconnecting external monitors", has 104 "Me too" votes. The author uses a 14-inch MacBook Pro M3 Pro closed, with two 1440p monitors on a CalDigit hub, and saw it on a fresh install of macOS Sonoma 14.4.1. A later thread describes the same thing on Sonoma 14.7.1. Between them they list:

  • The built-in screen comes back at another scaled resolution. Text and menus are too large or too small for the screen.
  • The size options disappear. System Settings → Displays shows a plain list of resolutions instead of the usual choices, and what you pick is either too small or blurry. The first author says the options only came back after a full restart.
  • The menu bar is laid out wrong. Items are spaced unevenly, icons on the right are squashed, and some menus or full-screen windows end up behind the notch.

Both authors had the MacBook closed with external monitors before unplugging, which is the common factor in these threads. I found no fix for it in Apple's release notes for macOS 15, 26 or 27.

If the problem is an external monitor's resolution after a wake rather than the built-in screen, see Mac resets monitor resolution, refresh rate or rotation after sleep. If it is the windows that end up piled on the laptop, see a MacBook, a dock and different monitors at home and at the office.

Check what macOS is using

With the MacBook alone, run this in Terminal:

system_profiler SPDisplaysDataType | grep -E "Resolution|UI Looks like"

"Resolution" is the panel's native resolution. "UI Looks like" is the scaled size macOS is using right now, followed by the refresh rate. Run it once on a day when the screen looks right and keep the result. After an undock that went wrong, run it again: if the "UI Looks like" line changed, macOS came back in a different mode, and you know which size to pick to get back.

Fixes without an app

  • Pick Default, or the size you wrote down. In System Settings → Displays, Apple recommends Default as the best resolution for the display. If the size options are shown as a list, Apple's guide says you can Control-click the list and choose Show Thumbnails, and that "Show resolutions as list" under Advanced makes the list permanent, so check it is off. One user in the Apple thread says Default made everything tiny after undocking, so compare with the "UI Looks like" value you saved.
  • Restart if the options are still missing. In the first thread, the normal size options only came back after a full restart. A reply in the second thread quotes an old Apple note on closed-lid use: you might have to open the display or restart your Mac to get it working properly.
  • Open the lid before you unplug. The first thread's author says the problem stops if they wake and unlock the Mac at the desk, wait for the desktops to load, open the lid so the built-in screen joins the external monitors, and only then unplug. It is one person's workaround, not something Apple documents, but it costs nothing to try.

The same author used BetterDisplay to choose 1512 x 982 (HiDPI), the size that looked right on their 14-inch screen, as a temporary fix. I have not tested BetterDisplay for this. More options for multi-monitor problems are in every fix for windows moving after sleep.

What those fixes do not cover

  • None of them stops it from happening on the next undock. Opening the lid first is the only one that tries, and it depends on you remembering it.
  • Picking a resolution sets the size, but the reports say the menu bar can stay laid out wrong until a restart.
  • Windows that macOS moved to the built-in screen when the monitors disappeared stay there. That is a separate problem, covered in the dock article linked above.

How Many Displays handles it

Many Displays remembers the mode of the built-in screen while the MacBook is on its own and nothing is changing, and treats that as the mode to keep. Right after you unplug, if the built-in screen comes back at a different resolution, it puts the last known good mode back. With the MacBook alone it never moves or resizes your windows: it only sets the mode, then goes idle.

Where it does not help:

  • It needs to have seen the right mode first. If you have never used the MacBook alone with the app running, there is nothing to go back to yet.
  • It only fixes the mode. It does not redraw the menu bar. If the menu bar stays wrong after the resolution is right, a restart is still the fix.
  • It only reacts right after a disconnect. If you change the resolution yourself later, that becomes the mode it keeps.

Questions

Why is my MacBook screen at the wrong resolution after I unplug the dock?

When the external monitors disappear, macOS has to switch the built-in screen back to its own mode. In the reports on Apple's forums this goes wrong most after using the MacBook closed with external monitors and then unplugging it: the built-in screen comes back at a different scaled resolution, sometimes with only a plain list of resolutions in System Settings.

How do I check which resolution the built-in screen is using?

Run system_profiler SPDisplaysDataType | grep -E "Resolution|UI Looks like" in Terminal with the MacBook alone. The UI Looks like line shows the scaled resolution and refresh rate macOS is using. Run it once when the screen looks right so you have something to compare with.

Does clicking Default in System Settings fix it?

Apple recommends Default as the best resolution for the display, and it is the first thing to try. In one Apple Community thread a user reports that Default made everything tiny after undocking, so it does not always bring back the size you had. In the first thread, the normal options only came back after a restart.

Can I avoid it before unplugging?

The author of the most followed Apple Community thread says it stops happening if they wake and unlock the Mac at the desk, open the lid so the built-in screen joins the external ones, and only then unplug. That is one user's workaround, not an Apple fix.
